### Skill Name
mblode/agent-skills

### Short Description
Nobody ships AI slop on purpose. These skills make sure you don't.

### Long Description
26 skills for UI audits, typography, docs, PR review, and releases (~19k installs via skills.sh). Covers React/Next UI quality, typography audits, AX audits for agentic products, PR review, and documentation writing.

### Use Cases
- Use case 1: Audit a React/Next UI for visual and interaction defects before shipping
- Use case 2: Run a typography audit with scoped rules and file:line findings
- Use case 3: Review a PR for structural issues and AI writing patterns

### Installation
```bash
npx skills add mblode/agent-skills -g --agent codex claude-code -y
```

### Examples
- `ui-design` for landing pages, dark mode, and UI defect audits
- `typography-audit` for font loading, type scales, and OpenType
- `pr-reviewer` for evidence-tiered read-only review
